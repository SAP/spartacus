# Sample Clean Skill

Use the facade pattern for all data access. Never inject the NgRx store directly
into components — always go through a facade.

See the Angular dependency injection guide at https://angular.dev/guide/di and
the RxJS docs at https://rxjs.dev for reactive patterns. Internationalization is
handled via https://www.i18next.com.

Related references:

- [Outlets](./references/outlets.md)
- [State management](references/state-management.md)

Legitimate typography and emoji are fine — em-dashes, arrows (→), and status
markers (✅ / ❌) must not be flagged.
